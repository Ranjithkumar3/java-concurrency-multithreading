# Java Concurrency Interview Lab

A hands-on Java 21 project for learning concurrency and multithreading one exercise at a time.

## Environment

- JDK 21
- Maven
- JUnit 5
- Base package: `io.github.ranjith.concurrency`

## Build

```shell
mvn clean test
```

## Learning workflow

The learner writes all Java source code and tests. The tutor designs exercises, reviews the learner's work, runs verification, and gives progressive hints without implementing solutions.

Progress is tracked in [`docs/PROGRESS.md`](docs/PROGRESS.md). Topic notes live in `docs/` and are written by the learner in their own words.
